1. Setup (once)

git clone https://github.com/YOU/ucgis-agentloom-2026-workshop
cd ucgis-agentloom-2026-workshop && git checkout -b workshop-YOU

# Windows
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python scripts\verify_workshop_machine.py
.venv\Scripts\python scripts\test_mcp_kg_tools.py

# macOS/Linux
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/verify_workshop_machine.py
.venv/bin/python scripts/test_mcp_kg_tools.py

Cline: OpenAI · gpt-5.2 · temp 0.2 · paste API key in settings

2. Dashboard (keep running)

.venv\Scripts\python -m uvicorn server.dashboard.app:app --port 8000 --host 127.0.0.1   # Windows
.venv/bin/python -m uvicorn server.dashboard.app:app --port 8000 --host 127.0.0.1       # macOS/Linux

Open http://127.0.0.1:8000 → Proposals tab. Windows: omit --reload.

3. Accept a proposal (human only)

.venv\Scripts\python scripts\kg\accept_proposal.py --proposal FILENAME.json   # Windows
.venv/bin/python scripts/kg/accept_proposal.py --proposal FILENAME.json        # macOS/Linux

Cline never runs accept. Review on dashboard first.

4. Validators (must PASS before commit)

.venv\Scripts\python scripts\validators\run_all.py   # Windows
.venv/bin/python scripts/validators/run_all.py        # macOS/Linux

5. Every Cline task — append

Do NOT read agents/knowledge-graphs/*-graph.json directly.
Use MCP kg_search / kg_get_node / kg_list_proposals for KG context.
