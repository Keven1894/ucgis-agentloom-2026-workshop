# Phase C — MCP: paste cline-mcp-settings.example.json (uses .venv python)

Propose → review loop

  1. Ask Cline to inspect your snapshot and propose KG nodes (use kg_search first).
  2. Cline runs python scripts/kg/propose_node.py … — approve when prompted.
  3. Open dashboard → Proposals tab — read title + justification.
  4. If satisfied: python scripts/kg/accept_proposal.py --proposal …
  5. Refresh dashboard — node appears on Graph + Timeline tabs.

Rules

  • Cline must never call accept_proposal.py — you accept.
  • MCP is read-only; mutations go through the CLIs only.
  • If MCP fails: Cline can fall back to selective file read (see .clinerules/02).
