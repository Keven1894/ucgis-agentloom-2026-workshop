Title

Florida river discharge (streamflow) — six USGS gaging stations, last 24 hours of 15-minute readings, shown on an interactive map.

Each blue marker is one USGS stream gage. Click a marker or use the station list below the map to see the latest discharge and a short sparkline.

Provenance

Data come from the U.S. Geological Survey (USGS) National Water Information System (NWIS), Instantaneous Values (IV) web service. This workshop page uses a vendored JSON snapshot (May 2026) so the demo works offline; the live feed URL is in the JSON-LD block.

USGS data are provisional and subject to revision. License and credits: USGS copyright policy.

Acquisition

Snapshot file: d3-usgs-nwis-fl-stations-24h.json (six site IDs, parameter 00060, period PT24H). Fetched once and stored under data/snapshots/ for reproducible workshop builds.

Serve this page with a local static server (python -m http.server) — browser security blocks fetch() on file:// URLs.

Data shape

Six river stations across Florida. Each record is discharge in cubic feet per second (cfs), USGS parameter code 00060, with latitude/longitude for mapping. Observations are 15-minute instantaneous values over roughly the past 24 hours.

Technical: nested NWIS JSON — value.timeSeries[] per site, values under values[].value[].

Processing

This page filters USGS missing-data sentinels (-999999), picks the latest valid reading per station, draws sparklines from the last 48 valid points, and plots markers on an OpenStreetMap basemap. No unit conversion applied.

Reuse

Cite USGS as the data source. Example: "Discharge data from USGS NWIS (parameter 00060), retrieved via waterservices.usgs.gov." Confirm provisional-data policy before publishing analysis or derivatives. Workshop scaffolding — not a production data portal.
