Title

Earthquakes of the past week — every event recorded by the USGS global network, plotted on an interactive map and sized by magnitude.

Each orange circle is one earthquake; bigger, brighter circles are stronger quakes. Click a circle or use the event list to see magnitude, depth, place, and the time it occurred.

Provenance

Data come from the U.S. Geological Survey (USGS) Earthquake Hazards Program real-time feed "All Earthquakes, Past Week". This workshop page uses a vendored GeoJSON snapshot so the demo works offline; the live feed URL is in the JSON-LD block.

USGS earthquake parameters are preliminary and subject to revision. License and credits: USGS copyright policy.

Acquisition

Snapshot file: d1-usgs-earthquakes-week.geojson — a standard GeoJSON FeatureCollection fetched once from the USGS summary feed and stored under data/snapshots/ for reproducible workshop builds.

Serve this page with a local static server (python -m http.server) — browser security blocks fetch() on file:// URLs.

Data shape

A GeoJSON FeatureCollection of point events. Each feature has geometry.coordinates = [longitude, latitude, depth_km] (longitude first) and properties including magnitude (mag), human-readable place, and the event time.

Technical: properties.time and properties.updated are Unix epoch milliseconds (not seconds, not ISO 8601). Many properties (felt, cdi, mmi, tsunami, alert) are frequently null.

Processing

This page reads each feature's coordinates (padding 2-tuples to depth null), converts the epoch-millisecond timestamp to a human-readable UTC string, sizes each circle marker by magnitude, and tolerates null optional fields. No magnitude filter is applied — every event in the snapshot is shown.

Cite USGS as the data source. Example: "Earthquake data from the USGS Earthquake Hazards Program real-time feed (all_week.geojson)." Earthquake parameters are preliminary — confirm before publishing analysis or derivatives. Workshop scaffolding — not a production seismic monitor.
