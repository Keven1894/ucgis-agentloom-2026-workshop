Title

Global air-quality monitoring locations — OpenAQ v3 station registry, first page of results plotted on an interactive map.

Each green marker is one monitoring location. Click for country, sensors measured (PM2.5, PM10, etc.), and provider metadata. This snapshot is locations only — time-series measurements need a follow-up API call per locationId.

Provenance

Data from OpenAQ v3 API (/v3/locations). Workshop uses vendored page-1 JSON; live refresh requires an X-API-Key header. OpenAQ aggregates government and research air-quality networks worldwide.

Acquisition

Snapshot: d2-openaq-locations-page1.json — 100 locations from GET /v3/locations?page=1&limit=100, stored under data/snapshots/. Serve via python -m http.server — not file://.

Data shape

Top-level { meta, results[] }. Each result has id, name, nested country, coordinates: { latitude, longitude } (object, not GeoJSON array), and sensors[] listing parameters/units. datetimeFirst/datetimeLast may be null on locations-only responses.

Processing

Filters out rows where coordinates is null or incomplete. Plots markers at lat/lon from the coordinate object. Popups list sensor parameters; no measurements time series in this view (see accepted KG node on two-call join).

Reuse

Cite OpenAQ and the underlying data providers. Register for an API key at openaq.org for live data. This catalog shows location metadata only — do not treat sensor lists as measurements. Workshop scaffolding, not a production air-quality portal.
