Title

World country boundaries — Natural Earth Admin 0 polygons at 1:10m scale, rendered as a choropleth basemap for exploration and join keys.

Click a country for name and ISO codes. This layer is a reference basemap — workshop catalogs join events or stations to these polygons; they do not ingest boundary geometry as if it were sensor readings.

Provenance

Natural Earth public domain cartographic data. Snapshot: ne_10m_admin_0_countries subset vendored as GeoJSON (~258 features, MultiPolygon/Polygon mix).

Acquisition

Vendored file d4-natural-earth-admin0.geojson under data/snapshots/. Large (~15 MB) — load once via fetch; serve with HTTP not file://.

Data shape

GeoJSON FeatureCollection. Properties use hyphenated ISO keys: ISO3166-1-Alpha-3, ISO3166-1-Alpha-2, plus name — not legacy iso_a2. Geometries are Polygon or MultiPolygon (Antarctica is complex).

Processing

L.geoJSON with semi-transparent fill; popups show name + ISO codes from hyphenated property names. Fit map to layer bounds after load. No simplification in-browser (workshop snapshot already generalised).

Reuse

Natural Earth terms apply; cite Natural Earth and the scale (1:10m). Use ISO Alpha-3 for joins to other datasets. Suitable for workshop choropleth demos — not for legal boundary disputes or high-precision cadastre.
